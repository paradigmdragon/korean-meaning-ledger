# 한글의미원장 · Korean Meaning Ledger

> 한국어와 다른 언어가 실제로 구별해 온 의미를 보존하고, AI의 판단 단위로 사용하기 위한 의미 정본과 Semantic Runtime.

한글의미원장은 번역어를 다시 번역하는 사전이 아닙니다.

**같은 의미는 연결하고, 다른 의미는 지우지 않고 따로 이름 붙입니다.**

번역 과정에서 하나의 단어로 겹쳐진 의미를 다시 살펴보고, 실제 의미의 범위·관계·경계를 구별하여 AI가 판단에 사용할 수 있는 구조로 만듭니다.

## 목표

이 프로젝트의 목표는 특정 AI 모델 하나를 만드는 것이 아닙니다.

- **Meaning Ledger** — 의미의 정체성, 정의, 범위, 관계, 출처와 변화를 보존합니다.
- **Semantic Runtime** — 현재 맥락에서 어떤 의미 차이를 확인해야 하는지, 어떤 Meaning을 적용해야 하는지 판단할 수 있는 실행 구조를 만듭니다.
- **Model Adapters** — Jev 같은 의미 판단 AI를 포함해 서로 다른 모델이 같은 Meaning 정본과 Runtime을 사용할 수 있게 합니다.

즉 모델이 바뀌어도 의미 정본과 판단 구조는 남도록 설계합니다.

## 기본 원칙

1. **표면어보다 의미를 먼저 봅니다.**
2. **같은 의미는 재사용하고 연결합니다.**
3. **겹치지만 남는 차이가 있으면 그 차이만 별도 Meaning으로 보존합니다.**
4. **다른 의미를 번역 편의를 위해 하나로 합치지 않습니다.**
5. **확정되지 않은 의미는 후보 상태로 남기고, 중앙 검수 후 정본으로 승격합니다.**
6. **의미 정의와 Runtime 구현을 분리합니다.**
7. **한국어 정본은 다른 언어를 배제하기 위한 것이 아니라, 번역 과정에서 사라질 수 있는 의미 차이를 보존하기 위한 기준점입니다.**

## 의미 제안 흐름

```text
표현 발견
  ↓
기존 Meaning 검색
  ↓
동일 / 부분 겹침 / 별개 판별
  ↓
기존 Meaning 재사용
또는 Revision / 신규 Meaning 제안
  ↓
근거·맥락·경계 기록
  ↓
중앙 검수
  ↓
Canonical Meaning
  ↓
Semantic Runtime에서 사용
```
