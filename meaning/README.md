# Meaning Ledger

이 디렉터리는 AI가 재사용할 수 있는 Meaning 정본과 그 관계를 다룹니다.

## 핵심 문장

> 같은 의미는 연결하고, 다른 의미는 지우지 않고 따로 이름 붙인다.

## Meaning이 저장해야 하는 것

최소:

- 의미 정체성
- 표면어
- 핵심 정의
- 상태
- provenance

필요할 때만:

- 동의어·번역어·기호
- 관계
- 뜻갈래
- revision
- 사례와 반례
- 적용 범위

## 저장하지 않는 것

Meaning 자체와 별개인 다음 정보는 다른 책임 계층에 둡니다.

- 작업 상태
- 실행 로그
- 임시 Work RAM
- 사용자 세션 상태
- 모델의 임시 추론
- 배포 상태

## 상태

이 저장소의 초기 공개 단계에서는 확정 Meaning과 탐구 후보를 반드시 구분합니다.

예를 들어 `사물 / 사태 / 사건 / 대상`은 현재 구조를 탐구 중이며, 저장소에 들어간다고 자동 canonical이 되는 것은 아닙니다.
