# Semantics

## 문제의식

서로 다른 언어의 단어가 번역 과정에서 하나의 대응어로 묶여도, 그 의미 범위와 단위가 반드시 같은 것은 아닙니다.

이 프로젝트는 번역을 폐기하지 않습니다. 대신 번역이 만든 연결과 의미 동일성을 분리합니다.

```text
translation relation ≠ semantic identity
similar direction ≠ same meaning
negation ≠ identity of the opposite
middle ≠ simple numeric midpoint
```

## 다시 단위화하기

우리는 기존 번역어를 다시 살펴보며 다음을 구별합니다.

1. 실제로 같은 의미
2. 일부가 겹치는 의미
3. 같은 표면어지만 다른 뜻갈래
4. 번역 과정에서 잘리거나 추가된 의미
5. 아직 판단할 수 없는 차이

이 작업의 목적은 모든 단어를 새로 정의하는 것이 아닙니다.

**기존 의미와 동일하면 그대로 사용하고, 남는 차이만 이름 붙입니다.**

## 한국어 정본의 역할

한국어는 이 원장에서 의미를 고정하기 위한 기준 언어입니다.

이는 다른 언어를 한국어로 환원한다는 뜻이 아닙니다. 오히려 각 언어의 고유한 의미 차이를 독립적으로 연결할 수 있도록 하나의 안정된 주소를 제공하는 것입니다.
